# MONITOR 桌面端 UI 规范（Tauri 前端）

目标：把原 egui 桌面取景器 1:1 复刻为 Web 前端，并新增「扫码无线」入口。
视觉沿用仓库 `web/assets/css/style.css` 的深色工作室风格：
- 背景 `#08090A`（带极轻径向光晕）、面板 `#101312`、描边 `rgba(233,235,228,.10)`
- 主文字 `#E9EBE4`、次要 `#7E857B`、信号色 `#D9FF3D`、危险 `#FF5138`
- 字体：system SF/PingFang；等宽用 SF Mono/Menlo；标题大写 + 字距
- 圆角 14px，克制阴影，微动效（150–300ms，尊重 prefers-reduced-motion）

## 布局（窗口 1180×800 起，可缩放，最小 860×560）

```
┌──────────────────────────────────────────────────────────┐

├────────────┬─────────────────────────────────────────────┤
│ 左侧 260px │ 取景区（黑色画布，居中，按比例框 fit/fill/stretch）│
│ 设备       │ 叠加：时间码 + 分辨率 + FPS、三分网格、REC 角标     │
│ 本机摄像头  │ 无信号时居中提示（选择设备 / 连接中 / 错误）        │
│ iPhone/iPad│                                              │
│ Android    │                                              │
│ 无线（扫码）│                                              │
│ ─────────  │                                              │
```

## 交互与快捷键（在输入框聚焦时不触发）

| 键 | 行为 |
| --- | --- |
| 空格 | 拍照 |
| G | 网格开关 |
| M | 镜像开关（预览与拍照同步镜像） |
| R | 开始/停止录像 |
| F | 全屏切换 |

- 设备列表每 10 秒自动刷新；「刷新」按钮立即刷新；选中项高亮。
- 切换设备时旧流断开、画布清空、状态回「连接中」。
- 画面比例：默认「跟随源」；预设 16:9、9:16、4:3、3:4、3:2、2:3、21:9、1:1；「自定义」两个数字输入（非法时提示且不改变布局）。
- fit/fill/stretch 与 egui 版一致：fit 完整留黑边；fill 居中裁切；stretch 拉伸。
- 拍照：白色闪光一闪（约 120ms），胶片条插入新项；失败 toast 提示。
- 录像：录中顶栏与画布右上角显示 ⏺ mm:ss，按钮变红「停止录像」。
- 胶片条：横向滚动；点击打开查看器（模态/浮层）：照片显示原图，视频显示 `<video controls>` 播放 mp4；
  按钮「打开」「在 Finder 中显示」「删除」。
- 右侧/左侧「无线（手机）」：点击后调用 `pair_info`，弹出配对浮层：
  - 显示二维码（`qrUrl`）、URL 文本（可点复制）、状态（等待手机连接 / 已连接：设备名）；
  - 提示：「手机与电脑同一 Wi-Fi；首次打开需信任本地证书」；`available=false` 时显示 hint；
  - 连接成功后浮层可关闭，画面自动切到无线源（调用 start_source kind=wireless）。

## 文件结构（必须）

```
ui/index.html          # 结构与图标（内联 SVG）
ui/styles.css          # 全部样式（含响应式与 reduced-motion）
ui/app.js              # 入口：状态、Tauri 调用、MJPEG 客户端、交互
ui/mjpeg.js            # 导出 parseMjpegStream / FrameReader（纯函数，可测试）
ui/layout.js           # 导出 computeLayout(srcW,srcH,availW,availH,ratio,mode) 与 PRESETS
ui/format.js           # 导出 formatClock/formatSecs/clamp 等
ui/tests/layout.test.mjs
ui/tests/mjpeg.test.mjs
```

`computeLayout` 返回 `{ box:{x,y,w,h}, dest:{x,y,w,h}, uv:{x,y,w,h} }`（与 egui `ratio::layout` 同语义）。

## 验收

1. `node --test ui/tests/` 全绿；
2. Tauri 窗口内：设备列表加载、选设备出画面、比例/模式切换正确、拍照/录像/胶片/查看器可用；
3. 无线浮层二维码可见，手机扫码页可打开；
4. 无控制台报错；字体与配色符合上述规范。
